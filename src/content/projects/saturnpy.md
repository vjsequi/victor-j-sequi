## Where it started

Transport modelling involves repeated work with matrices, assignment outputs, and network data. Those workflows were an early opportunity for me to connect domain knowledge with Python automation.

## The work

SATURNpy grew into a reusable Python layer for specialist modelling workflows, including matrices, assignment outputs, and geospatial visualisation.

The package was published to PyPI in 2019. It belongs to an earlier stage of my work, when I was moving from individual analyses towards tools that could support repeated tasks.

## Why it still belongs here

The project connects transport engineering, programming, and practical automation. It is an early example of a pattern that continues through my work: understand a domain well enough to make a useful tool for it.

## The result

Published in 2019, SATURNpy turned repeated modelling tasks into reusable tooling. This is a historical project, preserved here as part of the path from domain-specific analysis to software development.
